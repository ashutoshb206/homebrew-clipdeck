# Homebrew Tap for ClipDeck

This is the official [Homebrew](https://brew.sh) tap for **ClipDeck** — the native, privacy-first clipboard manager for macOS.

## Install

```bash
brew tap ashutoshb206/clipdeck
brew install --cask clipdeck
```

Or as a single command:

```bash
brew install --cask ashutoshb206/clipdeck/clipdeck
```

## Update

```bash
brew upgrade --cask clipdeck
```

## Uninstall

```bash
brew uninstall --cask clipdeck
```

## About ClipDeck

ClipDeck keeps everything you copy searchable and one keystroke away. Built with Swift + SwiftUI, it runs natively in your menu bar.
